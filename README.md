# JIZURA 字面 — 문자 PV 자동 구성 도구

**다른 언어판(원본 저장소):** [日本語](https://852wa.github.io/JIZURA/) · [English](https://852wa.github.io/JIZURA/en/) ([guide](README.en.md)) · [Bahasa Indonesia](https://852wa.github.io/JIZURA/id/) · [繁體中文](https://852wa.github.io/JIZURA/zh-hant/) · [简体中文](https://852wa.github.io/JIZURA/zh-hans/)　／　영어판 AE 패널: [ScriptUI](https://852wa.github.io/JIZURA/JIZURA_AE_en.jsx) · [CEP](https://852wa.github.io/JIZURA/JIZURA_CEP_en.zip)

가사를 넣으면 문자 PV(리릭 모션)에서 자주 쓰이는 표현을 조합해 컷을 자동으로 구성하고 MP4로 내보내는 브라우저 앱입니다. 레이아웃·동작·장식·컷 간 전환·마무리를 711개의 작은 부품(그리고 28개의 스타일)으로 갖추고 있고, 그 조합을 매번 바꾸므로 시드만 바꾸면 언제든지 다른 구성이 됩니다. After Effects용 패널(스크립트 버전과, 브라우저 버전 화면을 그대로 쓰는 CEP 버전)도 함께 제공됩니다.

**▶ 브라우저에서 사용: <https://852wa.github.io/JIZURA/>**　／　AE 패널: [JIZURA_AE.jsx](https://852wa.github.io/JIZURA/JIZURA_AE.jsx)(스크립트 버전. 링크를 우클릭 → 「이름을 지정하여 링크 대상 저장」)·[JIZURA_CEP.zip](https://852wa.github.io/JIZURA/JIZURA_CEP.zip)(CEP 버전)

- 설치 불필요. 가사·곡·내보내기는 모두 브라우저 안에서 처리되며 서버로 전송되지 않습니다(외부에서 불러오는 것은 Google Fonts의 글꼴뿐이며, 필요한 때에 지금 구성에서 사용하는 서체만 불러옵니다).
- 자동 버튼(키 `R`)을 누를 때마다 스타일·분위기·동작·색 배합·구성이 통째로 바뀝니다.
- 화면 비율 16:9 / 9:16 / 4:3 / 3:4 / 1:1 / 4:5 / 21:9, 720p〜4K, 24 / 30 / 60fps.
- 곡을 불러오면 박자를 감지해 컷을 맞춥니다. 탭으로 수동 동기화도 할 수 있습니다.
- MP4(곡 포함)·연속 PNG·투명 PNG로 내보내기. 배경을 **그린 스크린 / 블랙 배경**(흰 글자와 연출만)으로 해서 합성용 소재로도 내보낼 수 있습니다. After Effects에서 편집할 수 있는 구성 데이터(JSON)도 내보낼 수 있습니다.

### 동작 환경

- **MP4 내보내기**: WebCodecs를 지원하는 브라우저(Chrome / Edge 권장. Safari 16.4 이후·Firefox 130 이후도 WebCodecs를 지원하지만, H.264로 내보낼 수 있는지는 브라우저와 OS에 따라 다릅니다). 지원하지 않는 환경에서도 미리보기와 연속 PNG 내보내기는 사용할 수 있습니다.
- 글꼴은 Google Fonts에서, 필요한 때에 지금 구성에서 사용하는 서체만 불러옵니다(오프라인일 때는 PC의 글꼴로 대체).

## 자동(간편 모드)

오른쪽 위의 「간편 / 자세히」로 화면을 전환할 수 있습니다. 처음에는 간편 모드로 열립니다.

- **자동으로 만들기**(키보드 `R`도 가능): 누를 때마다 다음을 한꺼번에 무작위로 다시 정하고 처음부터 재생합니다.
  - 스타일(직전과 같은 것은 나오지 않음)
  - 분위기(글리치 / 차분함 / 팝 / 그래픽 / 에디토리얼 / 감성 / 전부 넣기). 분위기마다 동작 강도·글리치 양·사용하는 레이아웃과 등장·퇴장 기법이 달라집니다.
  - 제목용 서체나 명조 프레임 서체
  - 색 배합(가끔 강조색과 색 어긋남 A/B도 무작위로 정해집니다)
  - 컷 구성(시드)
- **◀ 이전 안 / 다음 안 ▶**: 자동으로 낸 안을 오갈 수 있습니다. 마음에 드는 안으로 돌아와서 내보낼 수 있습니다.
- **여기만 바꾸기**: 현재 안을 살린 채 일부만 다시 뽑습니다.
  - 스타일 / 색 배합(강조색·색 어긋남 A/B) / 분위기(동작과 사용 기법) / 구성(레이아웃과 동작의 조합)
- 가사·곡·타이밍·내보내기 설정은 자동에서 바뀌지 않습니다. 행 목록에서 자물쇠를 잠근 행도 그대로 남습니다.

### 무작위로 쓰는 연출의 범위

자동 버튼 아래(자세히 모드에서는 「기법」 탭 맨 위)에 있는 두 개의 체크로, 자동·셔플·행별 재추첨에서 뽑히는 연출을 정할 수 있습니다.

- **추가 연출도 사용**(기본값: 꺼짐): 꺼져 있으면 첫 공개 버전의 연출(부품 356개·스타일 12종)만 사용합니다. 켜면 나중에 추가된 연출(부품 355개·스타일 16종·서체 6종)도 후보가 됩니다.
- **일본풍 연출도 사용**(기본값: 켜짐): 등롱·엽서·쇼지·부채·가문·세이가이하·벚꽃 잎 같은 일본풍 그래픽과, 일본풍 스타일(벚꽃·먹과 주칠)입니다. 끄면 선택되지 않습니다. 이 판정은 추가 연출 체크 이후에 적용됩니다.
- 어느 쪽이든 행별로 레이아웃 등을 수동으로 지정했거나 스타일을 직접 골랐을 때는 관계없이 그대로 쓸 수 있습니다.
- 「기법」 탭과 스타일 목록에서는 추가 연출에 「추가」, 일본풍에 「일본풍」 표시가 붙습니다. 지금 설정으로 무작위로 뽑히지 않는 것은 흐리게 표시됩니다.

## 색 배합 무작위

「자세히」→「스타일」 탭의 「강조색·색 어긋남」에 있습니다.

- **색 배합 무작위**: 강조색과 색 어긋남 A/B(서로 어긋나는 두 색)을 조합으로 다시 고릅니다.
  - 절반 미만은 보색 관계 등으로 조화가 조절된 조합에서 고릅니다. 나머지는 색상환에서 매번 새로 만듭니다.
  - 배경 밝기에 맞춰 밝기를 자동 보정해 글자가 읽을 농도를 유지합니다(강조색은 배경과의 명도 대비 3 이상).
- 색을 직접 고를 수도 있습니다. 「내 색으로 덮어쓰기」를 해제하면 스타일 고유의 색으로 돌아옵니다.

## 브라우저 버전 사용법

1. **가사**: 한 줄이 한 구절입니다. 표기는 다음과 같습니다.
   - `새벽의 색을/기억해` … `/`로 컷의 경계 지정
   - `*투명*` … 강조(크고 임팩트 있는 연출이 선택되기 쉬워집니다)
   - 행 끝의 `!` … 플래시와 흔들림이 들어갑니다
   - `가사|주석` … 주석 레이아웃에 표시되는 작은 글자
   - `[01:23.45]가사` … LRC 타임스탬프를 그대로 사용합니다
   - `[00:12.00]<00:12.00>나는 <00:12.48>너를 <00:13.10>사랑해 <00:14.00>` … 확장 LRC 단어 시각. 컷이 단어가 불리는 시각에 맞춰 나뉘고, 「가라오케」 글자 가공이 실제로 부르는 속도로 채워지며 더 자주 선택됩니다(AE에서는 컷 경계만 반영)
   - `[간주 8]` … 다음 행 앞에 8초짜리 간주를 넣습니다(`[간주 8초]`, `[interlude 8]`, 원본 표기 `[間奏 8]`·`[inst]`도 가능). 앞 행은 원래 길이만큼만 표시되고, 남은 시간은 가사 없는 간주 컷(무작위 화면 효과 1개 포함)이 됩니다
   - `[간주 8 | Guitar Solo]` / `[간주 | 문구]` … 간주 화면 아래 작은 글자를 곡 제목 대신 이 문구로 표시합니다
   - `[01:20.00][간주]` … LRC 시각을 붙이면 앞 행이 그 시각에 끝나고 간주가 그 시각에 시작합니다
   - `[간주]` … 시간은 늘리지 않고, 앞 행과 다음 행 사이의 빈 공간을 간주 컷으로 채웁니다(자동 타이밍에서는 빈 줄만큼의 간격이 생깁니다)
   - LRC 타임스탬프나 수동 초수가 있는 행에서는 그 시간이 우선이며, 초 수는 무시되고 사이 공간만 간주 컷이 됩니다. 사이 공간이 0.3초보다 짧으면 간주 컷을 넣지 않습니다
   - `[마무리]` / `[End]` … 마지막 가사 뒤에 두면 곡 끝까지 엔드 카드(곡 제목·아티스트, 제목이 없으면 END)를 보여주고 페이드아웃합니다. 곡을 불러오지 않았다면 4초, `[마무리 8]`이면 8초입니다
   - `[03:45.00][마무리]` … LRC 시각을 붙이면 그 시각에 마지막 가사가 끝나고 엔드 카드가 시작됩니다. 가사 중간에 쓴 `[마무리]`는 무시됩니다
2. **곡과 타이밍**
   - 곡을 불러오면 BPM과 박자를 자동 감지하고, 컷의 경계를 박자에 맞춥니다. 불러온 곡은 이 브라우저에 저장되어, 페이지를 다시 열어도 자동으로 다시 불러옵니다(내보내기에서 오디오가 빠지지 않도록).
   - 「탭으로 동기화」를 누르면 곡이 재생됩니다. 각 행이 시작되는 순간에 Space를 누르세요. 잘못 눌렀다면 Backspace 또는 「한 번 되돌리기」. 행 목록의 ◎를 누르면 **그 행부터 다시 탭할 수 있습니다**(앞 행의 시각은 그대로).
   - 행 목록의 초수를 직접 고칠 수도 있습니다.
   - **타임라인**: 위쪽 눈금(행 구분)을 좌우로 드래그하면 그 행의 시작 시각을 바꿀 수 있습니다(박자에 맞춤, Shift로 자유롭게). ＋/−·휠로 확대·축소, Shift+휠로 좌우 이동, 「전체」로 되돌립니다.
   - 가사·타이밍 변경은 「되돌리기」(Ctrl+Z)로 취소할 수 있습니다.
3. **행별로 고치기**(간편 모드에서도 사용 가능)
   - ✎(또는 가사를 더블클릭)로 그 행의 가사를 그 자리에서 고칠 수 있습니다. 표기법도 그대로 쓸 수 있습니다.
   - 「컷 자동 / 1〜6」으로 그 행을 몇 컷으로 나눌지 정할 수 있습니다.
   - 행별 주사위로 그 행만 다시 뽑습니다. 자물쇠로 그 행의 구성을 고정하거나, 레이아웃을 직접 지정할 수도 있습니다(자세히 모드).
   - 「셔플」로 전체를 다시 뽑습니다.
4. **스타일**: 색 배합·서체·질감의 세트가 28종류가 있습니다(벚꽃 / 심해 / 노을 그라데이션 / 숲의 수첩 / 베이퍼 / 신문 / 신스80s / 크라프트지 / 캔디 / 애시드 / 먹과 주칠 / 금빛 밤 / 레트로 미디어 / 만화·스크린톤 / 네온·시티 / 미니멀·스위스 등을 포함). 새 4종은 한국어 글꼴(Noto Sans KR·Black Han Sans 등)을 쓰고, 기존 부품(VHS·브라운관 효과, 말풍선·집중선, 네온 간판, 스위스 그리드 등)을 스타일에 맞게 더 자주 고릅니다. 하나의 영상 안에서도 컷에 따라 배경색이 바뀝니다.
   - 서체는 Google Fonts의 18개 패밀리(Reggae One / Rampart One / Potta One / Kiwi Maru / Klee One / Shippori Mincho B1 포함)에서 고릅니다. **지금 구성에서 사용하는 글꼴만** 필요한 때에 불러오므로, 서체가 늘어나도 시작과 동작이 느려지지 않습니다.
   - 폰트는 다음 방법으로 바꿀 수 있습니다.
     - PC에 있는 폰트명 입력
     - .ttf / .otf 파일 불러오기
5. **연출과 기법**
   - 「연출」 탭에서 동작 강도·글리치·색 어긋남·장식 양·컷 세분화·질감·프레임 스텝을 조절합니다.
   - 간주 화면: 기본은 남은 초 / 원 2종류입니다. 「추가 연출도 사용」을 켜면 박 카운트다운(마지막 3박에 3·2·1), 다음 가사 미리보기, 곡 진행 바, 에너지 막대도 무작위로 나옵니다(브라우저 전용, AE에서는 원으로 대체). 곡의 박을 알면 간주 화면의 원과 막대가 박에 맞춰 튑니다. 6초보다 긴 간주는 2~3컷으로 나뉘어 배경색과 화면이 바뀝니다.
   - 「음악 반응」 슬라이더를 올리면 곡의 박과 음량에 맞춰 화면 전체가 커졌다 작아지고, 색 어긋남과 흔들림이 세집니다(곡을 불러왔을 때만, 브라우저 전용. 기본 0). 「자동」 생성은 분위기에 맞는 값을 고릅니다.
   - 「첫 간주에 크레딧」을 켜면 2초 이상인 첫 간주에 곡 제목과 아티스트를 크게 보여줍니다(AE 패널에도 있음).
   - 「간주 남은 초」로 간주 화면에 남은 초를 크게 표시할지 정합니다(무작위 / 항상 표시 / 숨김). AE 패널에도 같은 항목이 있습니다.
   - 「기법」 탭에서 10개 분류(레이아웃·등장·유지·퇴장·장식·글자 가공·배경·카메라·화면 효과·컷 간 전환)의 부품을 하나씩 ON/OFF할 수 있습니다(위의 「추가 연출도 사용」·「일본풍 연출도 사용」 체크와 조합해 판정됩니다). 분류별로 접혀 있으며, 「모두 ON / 모두 OFF / 반전」과 이름으로 검색할 수 있습니다.
6. **내보내기**
   - MP4(Chrome / Edge에서는 H.264. 곡도 포함할 수 있습니다)
   - 연속 PNG(ZIP)
   - 투명 PNG(ZIP·배경 없음. AE 등에서 합성용)
   - 「배경」에서 **그린 스크린 / 블랙 배경**을 고르면 흰 글자와 연출만 있는 합성용 소재가 됩니다(자세한 내용은 아래의 「합성용 배경」).
   - 화면 비율은 16:9 / 9:16 / 4:3 / 3:4 / 1:1 / 4:5 / 21:9, 해상도는 720p〜4K, 프레임 레이트는 24 / 30 / 60fps 중에서 고를 수 있습니다(자세한 내용은 아래의 「24 / 30 / 60fps로 내보내기」).
   - **선택한 행만 내보내기**: 「내보낼 범위」에서 첫 행과 마지막 행을 고르거나, 행 목록의 ⇥를 누릅니다(Shift+클릭으로 범위 확장). 파일 이름에 `_L03-05`처럼 행 번호가 붙습니다.
   - **내보내기가 잘 실패하지 않도록**: 동영상을 조금씩 기록하면서 만들어, 긴 곡이나 1080p·1440p에서도 메모리를 한꺼번에 쓰지 않습니다. GPU 인코더에서 실패하면 자동으로 소프트웨어 인코더로 바꿔 다시 씁니다. 백그라운드 탭에서 브라우저가 인코더를 회수해도 이어서 인코딩합니다.
   - **큰 동영상용(파일에 바로 저장)**: Chrome / Edge에서는 저장할 곳을 먼저 고르고 그곳에 바로 기록하는 버튼이 있습니다. 긴 곡을 높은 해상도로 내보낼 때 쓰세요.
   - 오디오: 브라우저가 AAC로 내보낼 수 없는 경우(Opus가 되거나 오디오를 내보낼 수 없는 경우)에는 iPhone·QuickTime에서 소리가 나지 않을 수 있으므로, 같은 길이의 오디오를 WAV로도 저장합니다.
- **통일감**(「연출」 탭 / 간편 모드의 체크): 켜면 문자 PV의 정석대로 구성합니다.
  - 파트(빈 행으로 나뉜 덩어리)마다 레이아웃·동작·카메라·장식을 맞춥니다. 반복되는 가사(후렴 등)는 첫 번째와 같은 방식으로 다시 나옵니다.
  - 동작 방향을 번갈아 쓰고(왼→오, 위→아래), 강한 동작은 결정적인 행에 돌립니다.
  - **키메(決め)**: 행 끝에 `!`를 붙인 행(없으면 반복되는 파트의 첫 행)을 한 컷으로 대담하게 보여줍니다(큰 글자·플래시·줌·흔들림).
  - **모프**: 같은 행의 다음 컷으로 넘어갈 때 같은 글자는 이동하고 나머지 글자는 녹듯이 바뀝니다.
  - **굵기**: 가끔 가는 글씨에서 굵은 글씨로 자라나듯 표시합니다(Noto Sans / Serif 가변 폰트).
- **문자 정렬**(같은 곳의 체크): 가나의 자간을 좁혀 덩어리로 읽히게 하고, 조사를 작게(일본어 は·が·を·に 등, 한국어 은·는·이·가·을·를·에·의 등), 행 첫 글자를 크게, 영문은 조금 크게 하고 본문과의 사이를 조금 띄웁니다. 글자는 목소리보다 0.2초 먼저 나오고, 효과가 너무 겹치지 않게 합니다(장식은 1개까지, 화면 효과는 컷마다 1개까지).
  - 두 가지 모두 기존 구성 방식은 그대로 남아 있어, 체크를 끄면 지금까지와 같습니다. AE 패널에는 선택된 레이아웃과 동작·타이밍이 들어갑니다(자간·글자 크기 조정, 굵기, 모프는 AE에서는 비슷한 표현이 됩니다).
- **가운데 비우기(캐릭터용)**: 「내보내기」 설정에 있는 체크입니다. 가운데에 캐릭터 등을 겹칠 것을 전제로, 가사를 둘로 나눠 가로 화면에서는 좌우, 세로 화면에서는 위아래 띠에 배치합니다(예: 「꽃이」｜「피었다」. 띠는 가로 화면에서 폭의 약 36%, 21:9는 30%, 세로 화면에서 높이의 33%). 좌우(위아래)는 같은 레이아웃·동작·장식·카메라의 한 장면이고, 뒤쪽 절반은 조금 늦게 나옵니다. 배경과 화면 효과는 화면 전체 그대로이며, 가사를 크게 배경에 그리는 배경(큰 한 글자)은 쓰지 않습니다. 한 단어뿐인 짧은 행은 양쪽에 같은 단어를 냅니다. 세로 화면에서는 「세로 화면일 때」로 위아래/좌우 중 나누는 방법을 고를 수 있습니다(좌우일 때 띠는 폭의 34%). 미리보기에는 비우는 범위를 점선으로 표시합니다(내보내기에는 들어가지 않습니다). AE 패널(스크립트 버전의 「가사에서」, CEP 버전, JSON)에서도 같은 배치가 됩니다.
- **화면 고정 표시**: 가로·세로가 충분한 화면에서는 페이지 전체가 스크롤되지 않고 가운데 미리보기와 타임라인이 항상 보입니다. 가사·행 목록(왼쪽)과 설정(오른쪽)은 각각의 열 안에서 스크롤됩니다. 재생 중에는 행 목록이 현재 행을 자동으로 따라갑니다(목록을 스크롤한 직후에는 멈춥니다). 좁은 화면에서는 지금까지처럼 페이지 전체가 스크롤됩니다.
- **가사 지우기/초기화**: 「가사 지우기」(가사 입력란 오른쪽 위)는 가사와 행별 타이밍·설정·내보낼 범위를 지웁니다. 「되돌리기」나 Ctrl+Z로 복구할 수 있습니다. 헤더의 「초기화」는 가사·곡(이 브라우저에 보관된 것 포함)·설정·안 기록·취소 기록을 모두 지우고 처음 상태로 되돌립니다(확인 후 실행, 되돌릴 수 없음). 표시 모드·음량·화면 언어는 그대로입니다.

7. **AE용 내보내기**: 현재 구성(타이밍·레이아웃·연출·색 배합)을 JSON으로 내보냅니다. AE 패널에서 불러오면 같은 구성을 그대로 편집할 수 있는 컴포가 됩니다.

### 화면 언어

이 포크의 화면은 한국어입니다. 오른쪽 위 언어 메뉴에서 원본 저장소의 日本語 / English / Bahasa Indonesia / 繁體中文 / 简体中文 판으로 이동할 수 있습니다. 프로젝트 저장 형식은 공통이라, 어느 언어판에서도 같은 파일을 열 수 있습니다.

### 미리보기 음량

재생 버튼 줄에 있는 음량 슬라이더로 미리보기 음량을 바꿀 수 있습니다. 「음량」 버튼을 누르면 음소거/해제되며 브라우저에 기억됩니다. 내보내는 MP4의 음량은 바뀌지 않습니다.

### 24 / 30 / 60fps로 내보내기

1. 「내보내기」 탭(간편 모드에서는 오른쪽의 「내보내기」 영역)에서 화면 비율·해상도·**fps**를 선택합니다.
2. 「MP4로 내보내기」를 누릅니다. 선택한 fps의 프레임 수 그대로 내보냅니다(예: 6초라면 24fps로 144장, 60fps로 360장).
3. 동작의 끊김 정도는 fps와는 별개로 「연출」 탭의 **프레임 스텝**으로 정해집니다.
   - **2프레임 스텝(12장/초)**: 문자 PV 특유의, 살짝 끊기는 동작. 어떤 fps로 내보내도 같은 모습이 됩니다(기본값).
   - **3프레임 스텝(8장/초)**: 더 애니메이션다운, 멈춤에 가까운 동작.
   - **풀**: 출력 fps 그대로 매 프레임 움직입니다. 60fps + 풀이 가장 매끄럽습니다(카메라 동작이나 흐르는 띠가 깔끔하게 보입니다).
4. 글리치나 깜빡임의 무작위 전환은 fps를 바꿔도 24fps 기준으로 같은 속도가 되도록 되어 있습니다. 60fps로 내보내도 번쩍임이 2배속이 되지 않습니다.
5. 기준: YouTube / MV라면 24fps(또는 30fps), SNS 세로 영상을 매끄럽게 하고 싶을 때는 30〜60fps + 풀. 60fps·4K는 내보내는 데 시간이 걸립니다.

AE 패널에서는 패널의 「fps」(24 / 30 / 60)로 컴포의 프레임 레이트를 고를 수 있습니다. JSON에서 만들 때는 브라우저 버전에서 선택한 fps의 컴포가 됩니다.

### 합성용 배경(그린 스크린 / 블랙 배경)

실사나 일러스트 영상 위에 가사만 겹치고 싶을 때 사용합니다.

1. 「내보내기」 탭(간단 모드에서는 오른쪽 「내보내기」 영역)의 **배경**에서 다음 중 하나를 고릅니다.
   - **일반**: 스타일의 색 배합·배경 그대로(기본값)
   - **그린 스크린**: `#00FF00` 위에 흰 글자와 연출만
   - **블랙 배경**: `#000000` 위에 흰 글자와 연출만
2. 미리보기에도 그대로 반영됩니다(오른쪽 위에 「그린 스크린」 등으로 표시됩니다). MP4·연속 PNG·투명 PNG 중 무엇으로 내보내도 같은 모습이 되며, 파일명 끝에 `_greenback` / `_blackback`이 붙습니다.
3. 합성 방법
   - 그린 스크린: 영상 편집 프로그램의 크로마 키(Premiere Pro의 Ultra 키, DaVinci Resolve의 3D 키어, AE의 Keylight 등)로 초록색을 뺍니다.
   - 블랙 배경: 블렌드 모드를 **스크린**(또는 더하기)으로 해서 겹치거나, 휘도 키로 검은색을 뺍니다.
   - 투명 PNG로 내보내면 처음부터 배경이 투명한 흰색 소재가 됩니다.

**투명 PNG 전경/후경(ZIP)**에서는 한 프레임마다 투명 PNG 2장을 zip 안의 서로 다른 폴더에 내보냅니다.
   - `back/`: 후경(배경 그래픽과 가사 뒤에 놓이는 장식)
   - `front/`: 전경(가사, 그 주변 장식·틀, 색 어긋남 고스트, HUD)
   - 화면 전체 효과(플래시·화면 분할 등)는 양쪽에 똑같이 걸리므로, `front`를 `back` 위에 겹치면 평소 모습이 됩니다(배경색·종이 질감·발광·주사선은 들어가지 않습니다).

투명 PNG에서는 화면 전체에 걸리는 효과(반전·플래시·스트로브·색상 이동·화면 분할·상하 슬라이드·브라운관 오프·검은 프레임 등)도 배경을 칠하지 않고 글자와 장식 부분에만 걸립니다(검은 프레임·흰 프레임은 빈 투명 프레임이 됩니다).

- 글자·장식·연출은 모두 흰색~회색의 단색이 됩니다. 스타일의 색 배합, 배경 무늬, 종이 질감, 입자, 주변 감광은 들어가지 않습니다(구성·동작·연출의 조합은 「일반」일 때와 같습니다).
- 색 어긋남의 고스트나 빛 번짐은 회색으로 그려지고, 키로 빼면 반투명이 됩니다. 그린 스크린은 「블랙 배경을 스크린 합성했을 때」와 같은 결과가 되도록 만들어져 있습니다.
- 플래시·반전·스트로브 등 화면 전체에 걸리는 연출은 그대로 흰 빛으로 남습니다. 필요 없으면 「연출」 탭에서 플래시를 끄거나 글리치를 약하게 하거나, 「기법」 탭의 「화면 효과」에서 개별로 꺼 주세요.
- AE 패널에서도 패널의 「배경」에서 같은 설정을 고를 수 있습니다. 「AE용 내보내기」의 JSON에도 배경 설정이 들어갑니다.

### 가사 언어(중국어·한국어 가사)

각 스타일의 서체는 일본어 글꼴을 전제로 하고 있어, 번체·간체·한글 가사에서는 글리프가 없는 글자만 다른 서체로 표시되어 한 줄 안에서 서체가 섞이는 경우가 있었습니다. 가사 입력란 아래의 **가사 언어**로 전환할 수 있습니다.

- **자동 판정**(기본값): 가나가 있으면 일본어, 한글이면 한국어, 한자만 있으면 번체/간체 고유 글자(們／们·說／说 등)로 판단합니다. 판정 결과는 입력란 옆에 표시됩니다.

## After Effects 패널 사용법

AE 패널은 두 종류가 있습니다. 어느 쪽이든 안의 생성 엔진은 같습니다.

- **스크립트 버전(`JIZURA_AE.jsx`)**: AE의 스크립트 패널. 가사로부터의 생성과 브라우저 버전 JSON 불러오기를 할 수 있습니다.
- **CEP 버전(`JIZURA_CEP.zip`)**: 브라우저 버전의 화면과 미리보기를 그대로 AE 안에서 쓸 수 있는 패널입니다. 「AE에서 컴포 생성」을 누르면 그 자리에서 컴포가 만들어집니다(아래의 「CEP 버전」).

### 설치 방법

1. `JIZURA_AE.jsx`를 다음 폴더에 넣고 AE를 재시작합니다.
   - Windows: `C:\Program Files\Adobe\Adobe After Effects <버전>\Support Files\Scripts\ScriptUI Panels\`
   - Mac: `/Applications/Adobe After Effects <버전>/Scripts/ScriptUI Panels/`
2. 메뉴의 「창(Window)」→「JIZURA_AE.jsx」로 패널이 열리며, 도킹할 수 있습니다.
3. 시험만 하려면 「파일 → 스크립트 → 스크립트 파일 실행」으로도 동작합니다(플로팅 윈도우가 됩니다).

### 사용법

- **가사에서**: 가사·스타일·크기·연출을 정하고 「컴포 생성」을 누릅니다.
  - 타이밍은 다음 3가지 중에서 고를 수 있습니다.
    - 자동(글자 수·BPM으로 계산)
    - 선택 레이어의 마커
    - 컴포 마커
  - 권장 절차: 곡 레이어를 선택한 뒤 재생하면서 키패드의 `*`로 각 행의 시작에 마커를 찍습니다. 「선택 레이어의 마커를 행 시작에 사용」을 선택해 생성합니다.
- **자동으로 생성**: 누를 때마다 스타일·분위기·연출 강도·2프레임 스텝/플래시/HUD·시드·색 배합을 무작위로 정해, 패널 표시에도 반영하면서 새 컴포를 만듭니다. 결과가 마음에 들면 거기서 값을 조절한 뒤 「컴포 생성」으로 다시 만들 수 있습니다.
- **분위기**(「연출」 영역): 고르면 그 분위기에 맞는 레이아웃·등장·퇴장 기법으로 좁혀 구성합니다. 어떤 기법으로 좁힐지는 시드로 정해지므로, 같은 시드면 같은 결과가 나옵니다.
- **강조색·색 어긋남**: 「색 배합 무작위」로 강조색과 색 어긋남 A/B를 다시 고릅니다. `#RRGGBB` 형식으로 직접 입력할 수도 있습니다. 「스타일 색 덮어쓰기」에 체크가 있으면 생성하는 컴포의 모든 장면에 적용합니다(밝기는 배경에 맞춰 자동 보정).
- **추가분·일본풍·배경**: 브라우저 버전과 같은 「추가분 연출도 사용」·「일본풍 연출도 사용」 체크와 「배경」(일반 / 그린 스크린 / 블랙 배경)을 고를 수 있습니다. 스타일은 28종 모두 고를 수 있습니다(목록의 〔추가〕〔일본풍〕이 표시입니다).
- **지원하는 부품**: 원본 브라우저 버전의 707개 부품 전부(레이아웃140·등장100·유지38·퇴장86·장식115·글자 가공52·배경62·카메라28·화면 효과66·컷 간 전환20)를 AE의 텍스트 레이어·셰이프 레이어·마스크·이펙트·표현식으로 구성합니다. 가사는 어느 부품에서도 텍스트 레이어 그대로이므로 나중에 고쳐 쓸 수 있습니다.
  - 3D 회전이나 종이가 넘어가는 움직임, 픽셀 단위 가공(픽셀 소트·디더 등)은 AE 기본 이펙트와 2D 변형으로 비슷한 모습으로 대체합니다.
  - 이 포크에서 추가한 부품(공간·손글씨 팩 등)처럼 패널이 모르는 부품 이름이 JSON에 있으면 가장 가까운 부품으로 바꿔 구성하고, 패널 아래 상태에 「교체 있음」을 표시합니다.
- **크기**: 1920×1080 / 1080×1920 / 1080×1080 / 3840×2160 / 1280×720 / 1440×1080(4:3) / 1080×1440(3:4), 또는 활성 컴포와 같은 크기.
- **JSON에서**: 브라우저 버전의 「AE용 내보내기」로 만든 JSON을 불러옵니다. 브라우저에서 정한 구성이 그대로 AE에서 조립됩니다.
- **폰트**
  - Noto Sans KR / Noto Serif KR / Black Han Sans / Noto Sans JP / Noto Serif JP / Dela Gothic One 등이 설치되어 있으면 자동으로 사용합니다(자동으로 고르는 것은 AE 2024 이후).
  - 설치되어 있지 않으면 「폰트」 탭에서 지정한 서체를 사용합니다. 기본값은 Malgun Gothic(맑은 고딕)·Batang(바탕)입니다.

- **경량**(AE에서 재생을 가볍게): 색 어긋남 복제·종이 질감·글로·입자·그림을 복제하는 화면 효과를 생략하고 만듭니다. 레이어 수가 약 40% 줄어, 긴 곡도 AE에서 가볍게 재생됩니다.
- **긴 곡**: 컴포를 조금씩 나눠 만들기 때문에 생성 중에도 After Effects가 「응답 없음」이 되지 않습니다. 패널에 진행 상황(%·컷 수)이 나오고, **중지**를 누르면 거기까지 만든 컷으로 컴포를 마무리합니다(스크립트 버전·CEP 버전 모두). 실행 취소가 잘게 나뉘므로, 다시 만들 때는 프로젝트 패널에서 컴포와 `cuts` 폴더를 지워 주세요.

- **진단 리포트**(「JSON에서」 탭): 마지막으로 만든 컴포의 표현식을 AE에서 계산시켜 오류와 교체 내용을 `JIZURA_report.txt`로 정리해 저장합니다. 생각대로 만들어지지 않을 때는 이 파일을 첨부해 알려 주세요.

### CEP 버전(브라우저 버전 화면을 AE 안에서)

1. [`JIZURA_CEP.zip`](https://852wa.github.io/JIZURA/JIZURA_CEP.zip)을 내려받아 압축을 풉니다.
2. Windows는 `install_win.bat`, Mac은 `install_mac.command`를 실행합니다(사용자 CEP 확장 폴더에 복사하고, 서명 없는 패널을 불러올 수 있도록 설정합니다).
3. After Effects(2022 이후)를 다시 시작하고 **창 → 확장 → JIZURA 字面**을 엽니다.

- 가사·스타일·연출을 정하는 방법은 브라우저 버전과 같습니다. **AE에서 컴포 생성**으로 현재 구성의 컴포가 그 자리에서 만들어집니다(한 번의 실행 취소로 되돌릴 수 있습니다).
- **내보낼 범위**로 행을 골라 두면 그 행만의 컴포를 만듭니다(곡도 같은 위치에 맞춰 들어갑니다). 긴 곡을 여러 번에 나눠 만들고 싶을 때 쓰세요. 「AE용 내보내기」의 JSON도 같은 범위가 됩니다.
- **AE에서 선택한 곡**: AE에서 곡 레이어를 고른 뒤 누르면 그 곡을 분석해 박자에 맞춥니다. 컴포에도 그 곡이 들어갑니다.
- **AE 마커를 행 시작에**: 선택 레이어(없으면 컴포)의 마커를 각 행의 시작 시각으로 씁니다.
- MP4·연속 PNG 내보내기도 패널에서 그대로 쓸 수 있습니다(저장 위치는 대화상자에서 고릅니다).
- 자세한 설치 방법과 배포용 서명 `.zxp`를 만드는 방법은 zip 안의 `README_CEP.md`에 있습니다.
- CEP 버전 패널은 원본 저장소의 배포본(일본어 UI)입니다. 이 포크의 한국어 화면으로 만들려면 `python3 build_cep.py`로 직접 빌드하세요.

### 생성되는 것

- 컷별 프리컴포(`JIZURA <곡명> cuts` 폴더)
  - 부품에 따라서는 컷 안에 프리컴포(`JZ … art` 등)나 색 어긋남용 복사본(`… ghost`: 종이·판 같은 배경 요소를 뺀 버전)이 더 만들어집니다.
- 생성이 끝나면 쓰이지 않는 숨김 레이어는 모두 삭제합니다. 남는 숨김 레이어는 트랙 매트(AE 규칙상 매트로 쓰는 레이어 자체는 표시되지 않습니다)뿐입니다.
  - 글자는 텍스트 애니메이터(표현 선택기)로 움직이므로, 글자를 바꿔도 동작이 유지됩니다.
- 색 어긋남은 각 컷을 시간차로 복제하고 「색조」 이펙트로 색을 입힌 고스트 레이어로 표현하고 있습니다.
- 맨 위의 `JZ FX` 조정 레이어에 다음이 모여 있습니다.
  - 2프레임 스텝(포스터화 시간)
  - 흔들림(트랜스폼)
  - 슬라이스 글리치(파형 워프)
  - 줌 블러 / 반전 / 글로우 / 노이즈
- `JZ Flash`·`JZ Vignette`·HUD(타임코드·행 카운터)도 생성됩니다.
- 배경을 그린 스크린 / 블랙 배경으로 한 경우에는 `JZ Vignette` 대신 맨 위에 `JZ Key Mono`(색조로 단색화하는 조정 레이어)가 들어가고, 그린 스크린에서는 추가로 `JZ Key Green`(블렌드 모드: 스크린)이 들어갑니다.

### 주의

- AE 2020 이후, 표현식 엔진은 JavaScript(새 프로젝트의 기본값)를 전제로 합니다.
- 이 패널은 AE의 객체 모델을 모방한 환경에서 검증했습니다. 707개 부품 각각을 여러 글자 수·화면 비율로 구성해 오류가 없는지, 전체 스타일 × 여러 시드의 자동 생성에서 오류가 없는지, 브라우저 버전의 같은 구성과 비교해 모양과 움직임이 맞는지 확인했습니다. 다만 실제 AE에서는 아직 실행해 보지 않았습니다. 이펙트 설정 등에서 예외적인 일이 있으면 생성 후 해당 항목을 목록으로 표시하고, 나머지 부분의 생성은 계속합니다.
- 부품이 많은 컷은 레이어와 표현식이 많아집니다. 긴 곡에서는 생성과 미리보기에 시간이 걸릴 수 있습니다(미리보기 해상도를 1/2~1/4로 하면 가벼워집니다).

## 개발·빌드

```
python3 build.py              # src/ app/ vendor/ → index.html(한국어판. 다른 언어판은 원본 저장소 배포본을 그대로 둠)
node tools/export_ae_data.js  # src/를 바꿀 때: ae/data.json(AE 패널이 쓰는 스타일·부품 정보) 갱신
python3 build_ae.py           # ae/(본체 + 이식된 팩 ae/p_*.jsx) → JIZURA_AE.jsx
python3 build_cep.py          # index.html + ae/ + cep/ → build/com.852wa.jizura/ 와 build/JIZURA_CEP.zip(공개용은 루트에 복사)
```
빌드에 필요한 것은 Python 3와 Node.js뿐입니다(npm 패키지는 불필요). AE 패널 테스트(AE 객체 모델을 모방한 환경에서 전체 스타일을 구성)는 `cd dev && npm install` 후 `node dev/ae_test.js`로 실행할 수 있습니다. 표현 부품을 추가할 때는 `docs/EXPRESSION_PACKS.md`를 참조하세요(테스트용 도구는 `dev/`). 로컬에서 실행·테스트하는 자세한 절차는 [`docs/LOCAL_SETUP.md`](docs/LOCAL_SETUP.md)를 참조하세요.

### 자신의 저장소로 공개하기(포크한 경우 등)

1. `index.html`이 저장소 루트에 있는 상태에서 push합니다.
2. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `/ (root)`로 설정하고 저장합니다.
3. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/`에서 열 수 있습니다.
