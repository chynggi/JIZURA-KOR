## 1. 병합 순서와 방식

1. `git merge upstream/main` → 충돌 해결(우리 쪽 기준 + 업스트림 로직) → 한국어화 → 커밋.
2. `git merge hirazisora/main` → 충돌 해결 → 한국어화 → 커밋.
3. 통합 작업(아래 2~5절) → 각각 커밋.

충돌 해결 규칙은 1차와 같다: 어느 쪽 기능도 지우지 않는다, 우리 한국어 문구 유지, README 링크·사이트 이름 교체 거부, `index.html`은 `build.py`로 재생성.

언어판: `en/`·`zh-hant/`·`zh-hans/`·`id/`·`ko/`는 이번에는 **업스트림 최신본으로 갱신**하고(업스트림이 만든 파일이므로), 업스트림이 새로 추가한 `vi/index.html`도 받는다. 우리 `build.py`의 언어 메뉴에 `('vi/index.html', 'vi', 'Tiếng Việt')`를 추가한다. `JIZURA_AE_en.jsx`, `JIZURA_CEP_en.zip`도 업스트림본으로 갱신한다.

AE 패널: `ae/`는 우리 한국어 원본에 업스트림 변경을 병합하고, 새 문구는 한국어로 옮긴 뒤 `python3 build_ae.py`로 `JIZURA_AE.jsx`를, `python3 build_cep.py`로 `JIZURA_CEP.zip`을 다시 만든다. `node tools/export_ae_data.js`로 `ae/data.json`을 갱신한다.

## 2. 한국어화

- 업스트림 새 부품 파일(`src/11p_typo*.js`, `11p_kinetic*.js`, `11p_horror*.js`)의 부품 이름·설명·태그, 새 스타일·분위기 이름, 새 UI 문구를 한국어로 옮긴다. 기존 `11p_*.js`의 번역 방식(이름 필드만 한국어, 키는 그대로)을 따른다.
- 포크 새 문구(`J.mediaLabel('日本語','English')` 형태)는 우리 쪽에서 한국어 문자열로 바꾼다. `J.mediaLabel`이 언어 인자를 받는 구조면 한국어 값을 쓰게 한다.
- `tools/check_fork_ko.sh`를 이번 병합 범위(`git diff 0578b12`)에도 쓸 수 있게 기준 커밋을 인자로 받도록 한다. 한자만으로 된 문구도 잡도록 검사를 보강한다(한글이 없는 줄 중 CJK 한자가 있는 UI 문자열).

## 3. 컷 편집 패널 통합

세 기능을 모두 살리고, 같은 컷을 다루는 UI는 **하나의 컷 패널**(업스트림의 컷 정보 패널을 바탕)로 모은다.

- 업스트림 컷별 선택: 레이아웃·수법 교체, 「이 컷만 셔플/자동」, 재생 위치 추적.
- 포크 컷 상세 편집기: 가사·미디어 레이어별 상세(블렌딩·불투명도 등).
- 우리 행별 후보 6개·우타하메: 해당 행의 컷일 때 같은 패널 안에 둔다.
- 같은 동작이 두 벌이면 하나로 합친다(예: 레이아웃 선택이 두 곳). 구체 배치는 병합 후 실제 화면을 보고 정하며, 결정은 계획 실행 중 리뷰에서 기록한다.
- 데이터: 업스트림의 컷별 선택 저장 필드, 포크의 컷 상세 필드, 우리 행 overrides(`area`, `lock`, 후보 필드)가 한 행/컷에 공존한다. 어느 경로도 다른 필드를 지우지 않는다(1차 규칙 유지).

## 4. 테마와 AI로 고르기

- 포크 선별 테마 12종(`11r_themes.js`)을 한국어 이름으로 들여온다(팝, 발라드, 록, 댄스·EDM, 힙합, 재즈, 어쿠스틱, 쿨, 귀여움, 우아함, 몽환, 레트로).
- 「AI로 고르기(β)」·`decision_server.py`는 그대로 둔다. 포크의 테마 UI와 AI 버튼이 같은 줄에 있으면 나란히 둔다.
- 업스트림 새 세트 스위치(타이포·키네틱·호러)가 `J.randomOk`에 반영되므로, AI로 고르기 선택지도 자동으로 스위치를 따른다. 호러 분위기도 선택지에 들어간다.

## 5. 포함 저장을 바이너리 형식으로 통일

- 「곡·소재 포함 저장」은 포크의 바이너리 형식(헤더 `JIZURA01` + UTF-8 JSON 목록 + 원본 파일들, base64 없음)으로 저장한다.
- 담는 것: 프로젝트 설정, 곡, 배경·전경 파일, 사용자 글꼴(포크 기존) + **우리 소재 파일과 피사체 마스크**(`asset:<id>`, `mask:<id>`). 목록 항목 `kind`에 `asset`, `mask`를 추가한다.
- 확장자: `.jizura`로 저장한다. 열기는 `.jizura`, `.jizuraichi`(포크), `.json`(일반 프로젝트, 1차 번들 v1·v2) 모두 받는다.
- 우리 1차의 JSON 번들 저장 코드(`saveBundle`의 base64 경로)는 없앤다. JSON 번들 **읽기**(`p.bundle` v2, `p.media.files` v1)는 유지한다.
- 일반 프로젝트 JSON 저장(설정만)은 그대로 둔다.
