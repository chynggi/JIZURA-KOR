# 인물 컷아웃

배경·전경 컷을 오른쪽 클릭 → 상세 편집 → 「인물 컷아웃」에서 사용합니다. 이미지와 동영상을 지원합니다.

1. 동영상이면 초당 분석 장수를 지정합니다.
2. 「인물 컷아웃 실행」을 누릅니다. 실사용 RVM MobileNetV3로 컷 안에서 재생하는 범위만 분석합니다. 추가할 장수, 다운로드, 초기화, 분석한 장수와 진행률을 표시합니다. 「처리 중지」로 중단할 수 있습니다.
3. 만든 뒤 「컷아웃 효과」의 「인물만 표시」「글자를 인물 뒤로」「전경을 인물 뒤로」를 체크합니다. 「인물만 표시」를 OFF로 하면 소재 전체를 표시합니다. 만든 직후에는 모두 OFF입니다.
4. 「적용」으로 컷에 저장합니다.

인물 컷아웃 실행 중에는 미리보기, 편집 탭, 기록, 다른 편집 항목, 「취소」「적용」을 회색으로 비활성화합니다. 모달 바깥 클릭이나 Esc 키로도 상세 편집이 닫히지 않습니다. 「처리 중지」는 사용할 수 있고, 완료·중지·실패 뒤에는 편집을 다시 시작할 수 있습니다.

## 소재 추적과 저장

마스크는 소재의 시각·좌표를 기준으로 저장합니다. 만드는 대상은 그 컷에서 재생하는 프레임뿐입니다. 소재의 위치, 크기, 회전, 연출을 바꿔도 따라갑니다. 같은 소재 지정인 채로 컷의 연출을 초기화해도 유지합니다. 소재를 바꾸면 옛 소재의 마스크를 적용하지 않습니다.

동영상 컷의 종료 시각·재생 시간·재생 시작 위치를 바꾼 뒤에는 인물 컷아웃을 다시 실행하세요. 같은 소재·초당 분석 장수의 마스크에서 부족한 만큼만 추가합니다. 줄인 범위의 마스크도 삭제하지 않고 나중에 다시 늘릴 때 재사용합니다. 반복 재생으로 같은 소재 프레임을 되풀이해도 같은 프레임을 중복 분석하지 않습니다. 모두 만들어져 있으면 모델을 읽거나 추론하지 않습니다.

예를 들어 소재 쪽 10~12초를 만든 뒤 10~15초로 늘리면 12~15초 프레임만 추가합니다. 초당 분석 장수를 바꾸면 현재 재생 범위를 다시 만듭니다. 범위는 분석 장수에 따른 프레임 단위로 판정합니다. 만들지 않은 범위는 다른 시각의 마스크로 대신하지 않고, 컷아웃 효과를 켠 내보내기에서는 다시 실행을 요구합니다.

분석 결과는 최대 변 512px 투명 PNG 열로 브라우저의 소재용 저장소에 저장하고, 컷에는 참조와 표시 설정을 저장합니다. 보통 미리보기·내보내기에서는 모델을 다시 실행하지 않습니다. 동영상은 분석할 때의 초당 장수로 마스크를 고르므로 분석 장수가 적으면 빠른 움직임에서 어긋날 수 있습니다.

미리보기에서는 각 마스크를 다음 분석 시각까지 표시하고 다음 2프레임을 미리 읽습니다. 다음 PNG를 읽는 동안에는 직전 마스크를 유지해 마스크 없이 표시되는 깜박임을 막습니다. 내보내기에서는 그 시각의 마스크를 다 읽은 뒤에 그립니다. 아직 만들지 않은 범위에는 이 읽기 대기용 대체 마스크를 적용하지 않습니다.

「저장」의 소재 포함 `.jizuraichi` 파일에는 마스크도 들어 있어 다른 브라우저에서도 복원할 수 있습니다. 저장소 삭제·자동 삭제에 대비해 파일을 저장하세요. 브라우저 저장에 실패하면 기존 소재와 마찬가지로 세션 중에만 보관합니다. After Effects용 구성 데이터에는 인물 마스크 그리기 기능이 포함되지 않습니다.

## 다운로드·부하

| 모델 | 모델 용량 | 브라우저 실행 |
| --- | --- | --- |
| RVM MobileNetV3(공식 TFJS int8판) | 약 4MB | TensorFlow.js 4.22.0 / WebGL. 사용할 수 없으면 CPU |

모델과 추론 라이브러리를 처음 사용할 때 외부에서 받아 옵니다. 소재, 분석 결과를 서버로 보내는 처리는 없습니다. 모델은 Cache Storage에 저장하고 같은 모델을 다음에 쓸 때 재사용합니다. 용량 부족, 시크릿 브라우징, 브라우저에 의한 삭제 등으로 캐시할 수 없거나 사라지면 다시 받아 옵니다. 라이브러리는 보통 HTTP 캐시를 쓰므로 완전한 오프라인 동작은 보장하지 않습니다.

분석은 Web Worker에서 하여 조작 화면의 부하를 줄입니다. 동영상은 컷 안에서 필요한 미생성 프레임만 분석하므로 부족한 재생 범위의 길이와 초당 분석 장수에 비례해 시간·저장 용량이 늘어납니다. 분석 장수를 낮추면 컷아웃이 빨리 끝나지만 빠른 움직임에서 마스크가 어긋나기 쉽습니다. iPhone 실기기에서의 동작·속도는 검증하지 않았습니다.

RVM은 새로 분석하는 연속 구간 안에서 프레임 사이 상태를 이어받습니다. 이미 분석한 프레임을 건너뛰고 다른 추가 구간을 분석할 때는 상태를 초기화합니다.

옛 버전에서 다른 분석 방식으로 만든 마스크도 저장·재생할 수 있습니다. 다시 실행하면 현재 컷 범위를 RVM으로 다시 만듭니다. 이전의 「인물을 삭제」 설정은 보통 표시로 취급합니다.

## 이용 조건

RVM의 공개 저장소는 GPL-3.0입니다. RVM을 포함한 구성을 재배포할 때 MIT만의 배포로 다루지 말고, GPL의 적용 범위·소스 제공 등의 조건을 확인하세요. RVM의 README는 코드의 GPL 재공개를 적고 있으며, 가중치만의 별도 라이선스는 명시되어 있지 않습니다.

출처, 고정한 모델의 받는 곳, 라이선스 본문은 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)에 적었습니다. 기존 JIZURA의 MIT 저작권 표시는 유지합니다.

## 개발 시 검증

포크에서 가져온 인물 컷아웃은 이 저장소에서 한국어 UI와 함께 이식했고, 검증은 `dev/fork_ui_test.py`의 포크 UI 테스트와 실제 화면 확인으로 합니다. 포크의 Node 전용 테스트(`person_cutout_test.cjs` 등)는 이식하지 않았습니다.

실행 중 편집 잠금, 모달 바깥 클릭·Esc 연타·폼 제출로 인한 종료 방지, 모바일 폭에서 처리 중지, 완료·중지·실패 뒤 잠금 해제를 실제로 확인해야 합니다.
